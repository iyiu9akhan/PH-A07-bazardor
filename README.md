## Project Name : BazarDor (বাজার দর)

## Description:

BazarDor is a modern, feature-rich web application designed to help users track, monitor, and compare daily market prices of essential commodities in Bangladesh (such as rice, lentils, oil, vegetables, fish, meat, eggs, dairy, and spices). By providing real-time price updates, trend indicators (price increases/decreases with exact percentages), and categorized breakdowns, BazarDor empowers consumers to stay informed and manage their daily grocery budgets effectively.

## Technologies Used

- **Languages:** JavaScript (JS), TypeScript (TS)
- **Frontend Framework:** Next.js (App Router), React
- **Styling & UI:** Tailwind CSS, DaisyUI
- **Authentication:** BetterAuth
- **Backend & Database:** Node.js, MongoDB

## Features :

- \*\* Real-time price fluctuation tracker
- \*\* Category navigation
- \*\* Live ticker & market overview
- \*\* User authentication & social logins
- \*\* Protected product details route (Requires authentication to view details)
- \*\* Interactive profile
- \*\* Interactive toast notifications
- \*\* Seamless signin and login
